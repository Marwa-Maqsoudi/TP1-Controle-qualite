# TP1 — Contrôle qualité d'une ligne d'usinage

## Description

Ce projet consiste à développer un programme Python permettant d'analyser des mesures issues d'une ligne d'usinage afin de vérifier leur conformité aux spécifications.

## Objectifs

- Calculer l'écart entre une mesure et la valeur nominale.
- Déterminer si une mesure est conforme aux tolérances.
- Analyser les données d'une ligne de production.
- Générer un histogramme textuel des mesures.
- Utiliser des tests automatisés avec `pytest`.

## Technologies utilisées

- Python
- pytest
- Git et GitHub

## Installation

Cloner le dépôt :

```bash
git clone https://github.com/Marwa-Maqsoudi/TP1-Controle-qualite.git
cd TP1-Controle-qualite
```

Installer les dépendances :

```bash
pip install -r requirements.txt
```

## Exécution

Lancer le programme :

```bash
python main.py
```

## Tests

Exécuter les tests automatisés :

```bash
pytest -q
```
